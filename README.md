# 왁스팝

같은 색 왁뿌볼을 드래그로 연결해 터뜨리는 단계형 퍼즐입니다.
바삭한 껍질이 깨지고 말랑한 속이 흔들리는 소리와 움직임을 중요하게 봅니다.
