# 왁스팝 / Wax Pop

같은 색 볼을 이어 얇은 껍질을 깨고 말랑한 속을 터뜨리는 모바일 퍼즐입니다.
현재 결과물은 자료 조사와 생성 목업을 담은 검토본입니다. 게임 코드는 아닙니다.

실물27장 관찰, CC0 소리32개, 생성 목업15종을 준비합니다. 공개 HTML에 사진3장만 넣고 허가 불명 상품 사진은 링크와 관찰만 남깁니다.
실제 왁스 녹음0개, 직접 청음·실제 iPad·플레이 난이도는 미검증입니다.
Freesound8개는 공개 미리듣기 MP3이고 고해상도 원본이 아닙니다. 원본 파일과 HTML용 미리듣기는 구분합니다.

재생성: Python3 + Pillow 환경에서 python 소스/build_review.py. 외부 요청 없이 포함한 파일로 재생성합니다.
