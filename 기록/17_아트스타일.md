# 볼과 화면 색 제안

2026-10-15. 상태: 비교 시안. 사용자의 선택 전이며 그림체·팔레트를 확정하지 않았습니다.

사용자는 팝스럽고 상큼하며 달달할 것 같은 귀여운 UI를 원합니다. 기본 볼4종을 먼저 보고 하나를 기준으로 이후 그림체를 맞추기로 했습니다. 이4종은 실제 사진이 아닌 생성 이미지입니다.

## 기본 볼 4종

같은 민트색·정면·왼쪽 위 조명으로 요청했습니다. 실제 결과의 윤곽·빛·여백은 조금씩 다릅니다. 색4종을 정한 것이 아니라 그림체4종을 비교하는 작업입니다.

| ID | 이름 | 직접 본 차이 | 남은 손질 |
| --- | --- | --- | --- |
| B01 | 밀키왁스 | 뽀얀 민트, 넓은 부드러운 반사, 둥근 부피감 | 반사와 투명 가장자리를 정리하고 파열 상태에서 껍질·속을 구분 |
| B02 | 그래픽팝 | 짙은 민트 외곽선과 큼직한 명암 면. 형태가 가장 또렷함 | 요청한3단계보다 부드러운 음영이 더 남음. 작은 화면에서 선 두께 비교 |
| B03 | 밀크젤리 | 진한 중심과 밝은 바깥쪽, 반투명하고 촉촉한 느낌 | 유리처럼 보일 수 있는 강한 반사를 줄일 후보 |
| B04 | 소프트클레이 | 무광 표면의 작은 결과 조각한 듯한 덩어리 | 작은 셀에서는 잔결을 줄이고 속의 말랑함을 별도 표현 |

현재 추천은 **B01**입니다. 볼의 둥근 귀여움과 뽀얀 재질을 함께 살릴 수 있습니다. 더 선명하고 만화 같은 방향을 원하면B02가 대안입니다. 눌림·파열·48px 실제 보드의 가독성은 아직 플레이로 확인하지 않았습니다.

원본: `목업/스타일/B01_밀키왁스.png`부터B04까지. 모두PNG RGBA이며 알파0~255를 확인했습니다. 실제 크기는 약1303×1207px로, 요청한 정사각 출력이 그대로 나온 것은 아닙니다. 재단·배율·중심점·투명 테두리는 선택한 시안을 게임용으로 준비할 때 정리합니다.

| ID | 이름 | 볼4색 | 화면 방향 |

| P1 | 소다 피치 · 추천 | `#4ED9BD` `#FF9D80` `#B69AFF` `#FFD56B` | 크림 배경·민트 보드·복숭아 분홍 버튼. 상큼함과 달달함을 함께 표현 |
| P2 | 베리 레몬 | `#68DBBB` `#FFA089` `#C19BEF` `#FFE077` | 딸기 우유 배경·베리 분홍 버튼. 더 달고 발랄한 느낌 |
| P3 | 트로피컬 구미 | `#32CDB1` `#FF906F` `#A88AEF` `#F7D35D` | 소다 배경·코랄 버튼. 더 시원하고 활기찬 느낌 |

추천 조합은 **B01+P1**이며 아직 선택된 기준은 아닙니다. 원래 민트·복숭아·연보라·크림 방향을 유지하면서 보드의 색 구별을 위해 크림은 레몬빛으로 제안했습니다.

밝은 버튼에는 짙은 글자를 씁니다. 지정한 글자색과 배경·패널·보드·버튼의 수치상 명암비를 계산했으며 가장 낮은 조합도 약5.73:1입니다. 최종 UI 전체의 접근성을 통과했다는 뜻은 아닙니다. 볼은 색 외 표면 무늬도 필요합니다. 배경·패널·보드·글자·버튼의 정확한 값은 [팔레트JSON](../소스/스타일팔레트.json)에 있습니다.

## 선택한 뒤 고정할 기준

- 원본 시안1장을 기준 이미지로 보존하고 이후 생성에 함께 참조합니다.
- 윤곽·카메라·빛 방향·반사의 크기·색·표면 무늬·배경 투명 조건을 적습니다.
- 먼저 선택한 볼의4색을 만들고 같은 보드에 놓습니다. 그다음 크런치볼·눌림·금·파열을 만듭니다.
- 한 번에 바꾸는 것은 색 또는 상태처럼 한 가지로 줄입니다. 형태가 다른 새 볼을 매번 다시 만들지 않습니다.
- 프롬프트와 참조 이미지만으로 완벽한 일관성이 보장되지는 않습니다. 작은 크기·밝고 짙은 배경·중심점·알파 가장자리를 확인합니다.

UI는 둥근 버튼·짧은 글자·큼직한 목표·단순한 패널을 기본으로 제안합니다. 젤리 장식은 버튼과 제목 주변에만 적게 두고 보드와 목표를 읽을 공간을 확보합니다. 팔레트 비교의 CSS 색 원과 버튼은 색 적용 예시이며 완성 게임 목업이 아닙니다.
