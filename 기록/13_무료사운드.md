# 무료 사운드

CC0 파일 32개를 확보하고 모두 해독했습니다. 직접 들었다고 쓰지 않습니다.
실제 슬라임·젤리 녹음 8개는 공개 MP3 미리듣기입니다. 고해상도 원본 WAV/FLAC는 로그인 필요로 받지 않았습니다. 자동으로 골라 자른 미리듣기 구간이 좋은 테이크라는 뜻은 아닙니다.
실제 왁스 껍질 녹음은 0개입니다. 목표 재질 전체를 확보한 것으로 보지 않습니다. 종이·유리·천은 보조 후보이며 왁스 녹음으로 세지 않습니다.
Freesound 개별 페이지의 CC0, Kenney 각 배포 팩의 LICENSE를 확인했습니다. Starter Kit README는 코드 MIT와 소리 CC0를 따로 명시합니다. NC·ND 자료는 넣지 않았습니다.

## 파일 검사와 변환

원본은 그대로 보존합니다. 미리듣기 폴더에 별도 MP3를 만듭니다. 긴 녹음은 첫 유효 신호 앞 60ms부터 최대7초를 자동 추출합니다. 보조 효과음은 최대3초입니다. 원본의 피크를 바탕으로 음량을 조정한 뒤 MP3를 다시 해독해 피크가 약 -6dBFS가 되도록 원본에서 다시 만들었습니다. MP3 변환 뒤 피크가 커지는 경우를 재검사하고 모두 1.0 미만임을 확인합니다. 모노44.1kHz/96kbps, 앞8ms·뒤40ms 페이드를 적용했습니다. 이는 음질 보증이나 청음 평가가 아닙니다.
book_flip_1.ogg(A023)은 디코딩 피크 1.056049로 1.0을 넘습니다. 원본을 보존하고 미리듣기는 감쇠했습니다. 손상·왜곡이 들리는지는 미확인입니다. 압축 음원 해독 시의 초과 값만으로 원본 녹음의 클리핑을 단정하지 않습니다.
같은 문제가 나온 A004·A005·A025·A028도 목록에서 표시합니다. 최대 피크·RMS·초과 샘플 수·길이·형식은 JSON에 기록했습니다. 미리듣기도 별도로 다시 해독해 검사합니다.

## 사람이 이어서 확인할 것

이어폰: 저음 바람·쉿 소리·말소리·음악·큰 울림·잘린 끝을 듣습니다.
휴대폰: 작은 소리도 들리는지, 고음이 따갑지 않은지, 연속 연결 때 피곤하지 않은지 듣습니다.
같은 음량에서 후보를 번갈아 듣고 원본에서 더 좋은 구간을 고릅니다. 슬라임 소리가 거칠거나 불쾌하면 제외합니다. 실제 왁스를 직접 녹음해 보조 유리·종이 소리와 비교합니다.
