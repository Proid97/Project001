# 02 기획정리

## 플레이어가 느껴야 할 것

손가락으로 같은 색 볼을 잇고, 손을 떼면 바삭하게 터집니다.
말랑한 속의 움직임과 소리가 다시 한 번 연결하고 싶게 만드는 것이 목표입니다.
세부 연출과 입력 방식은 아직 정해지지 않았습니다.

## 첫 설계의 뜻

| 설계안 | 확인할 것 |
| --- | --- |
| 7×8칸 | 볼이 잘 보이고 손가락으로 고르기 편한가? |
| 같은 색 3개 이상 연결 | 연결할 길이 충분하고 실수가 적은가? |
| 6개 이상 연결 시 특수 볼 | 긴 연결을 노릴 이유가 생기는가? |
| 특수 볼의 주변 3×3칸 파열 | 효과를 쉽게 알아보고 시원하게 느끼는가? |
| 첫 12단계 | 규칙을 배우면서 반복 플레이가 재미있는가? |

이 표는 검증 질문입니다. 플레이 결과나 확정 수치가 아닙니다.

## 구현 전에 정할 규칙

- 연결 방향: 가로·세로만 가능한지, 대각선도 가능한지.
- 되짚기와 취소: 이전 볼로 돌아갔을 때 연결을 줄일지, 판 밖에서 놓으면 어떻게 할지.
- 파열 뒤 처리: 빈칸을 어떻게 채울지, 움직이는 동안 입력을 받을지.
- 특수 볼: 생성 위치, 발동 방법, 생성 즉시 터지는지, 연쇄 반응 여부.
- 단계: 성공 목표, 이동 횟수 또는 시간 제한, 실패와 재시도 방식.
- 연결할 길이 없을 때: 다시 섞을지, 실패로 볼지.

위 항목은 현재 전달 내용만으로 확인할 수 없습니다. 이전 기획 원본에 정해진 내용이 있으면 먼저 따릅니다.

## 자료 조사와 목업의 연결

실물 사진에서는 껍질 두께, 균열, 속의 비침, 눌림과 복원을 봅니다.
소리에서는 껍질이 깨지는 짧은 소리와 속이 눌리는 소리를 나누어 들어 봅니다.
이것은 앞으로 볼 기준이며 실제 조사 결과가 아닙니다.

첫 목업은 기본 화면, 드래그 중 화면, 파열 순간 화면입니다.
사진과 소리 조사가 끝난 뒤 형태·색·움직임·소리를 함께 비교합니다.
