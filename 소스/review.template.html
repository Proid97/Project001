바삭한 껍질,
말랑한 한 번 더.

같은 색 왁뿌볼을 손가락으로 이어 터뜨리는 세로 퍼즐. 소리와 눌림이 다시 하고 싶은 마음을 만듭니다.

7 × 8 보드4색 · 첫 12단계

조사와 예상 완성 모습입니다.
게임 코드·움직임·난이도는 아직 검증 전입니다.

이번에 만든 것

  • 실물 사진 파일과 직접 관찰 메모
  • CC0 음원과 음량 검사, 별도 미리듣기
  • 같은 재질로 만든 화면 생성 목업
  • 외부 파일 요청 없는 단일 검토 HTML

남은 확인

  • 실물 재질 녹음 8개를 확보했지만 실제 왁스 껍질은 0개
  • 슬라임·젤리 8개는 공개 MP3. 고해상도 원본 미확보
  • 구형 왁스볼 상태 사진 6장 목표 중 3장. 다른 3장은 보조 자료
  • 영상의 눌림·복원 속도, 실제 청음·iPad 시험
  • 목업의 실제 움직임과 단계별 난이도 시험
사진 27장은 원본 모습으로 저장해 관찰했습니다. 공개 허가가 확인된 3장만 이 HTML에 넣었습니다. 나머지 24장은 원문 링크와 메모로 검토하세요. 생성 목업은 실물 자료 수에 포함하지 않습니다.

다음 작업

① 왁스볼의 깨지기 전·중·후를 직접 촬영하고 소리를 녹음합니다. ② 이어폰과 휴대폰으로 후보를 듣고 10개 안팎으로 줄입니다. ③ 눌림→껍질 파열→속 흔들림을 짧은 동작으로 만듭니다. ④ 12단계를 플레이하며 횟수와 목표를 조정합니다.

검토 표시는 이 브라우저에 저장됩니다. HTML 파일 자체가 자동으로 바뀌지는 않습니다. 다른 기기로 옮길 때 JSON 저장을 사용하세요.
